Discord slash commands

Names below are for the normal bot. The development bot adds a dev- prefix. Command cooldowns shown here are Sapphire registration settings. Some features also apply limits while a command is running.

/adicionar-a-fila

Section titled “/adicionar-a-fila”

Adiciona uma música ao topo da fila

  • Discord permissions No explicit member permission flag.
  • Cooldown No Sapphire cooldown configured.
  • Runtime preconditions UserInVoiceChannel, BotNotInOtherChannel, CanSpeak, CanJoin
  • musica (String, required) — A música a ser tocada
  • posicao (Number, optional) — A posição que a música deve ser adicionada

Command implementation

/admin

Section titled “/admin”

Comandos administrativos

  • Discord permissions Administrator
  • Cooldown 1 use per 5 seconds
  • status (Subcommand) — Mostra o status atual do bot (API, sessões, erros, uptime)
  • termo (SubcommandGroup) — Gerenciar o jogo Termo
    • novo (Subcommand) — Força uma nova palavra para o Termo (uso em testes)
    • canal (Subcommand) — Define o canal onde o Termo envia mensagens públicas
      • canal (Channel, required, GuildText) — Canal de texto para o Termo
    • status (Subcommand) — Envia o status de hoje no canal do Termo (sem revelar a palavra)
    • leaderboard (Subcommand) — Veja o ranking do Terminhos
      • periodo (String, required) — Período do ranking
        • Hoje (daily)
        • Esta semana (weekly)
        • Este mês (monthly)
        • Histórico (all-time)
    • meta (Subcommand) — Agenda uma meta coletiva para o Terminhos
      • alvo (Integer, required, min 1, max 100000) — Participações distintas necessárias
      • inicio (String, required) — Primeiro dia, AAAA-MM-DD (Recife)
      • fim (String, required) — Último dia, AAAA-MM-DD (Recife)
    • anuncios (Subcommand) — Configura anúncios comunitários do Terminhos
      • coletivo (Boolean, required) — Anunciar páginas e metas concluídas
      • resumo (Boolean, required) — Publicar resumo e galeria semanais
      • canal (Channel, optional, GuildText) — Canal de anúncios; omita para manter pendentes
    • incertos (Subcommand) — Lista anúncios que precisam de conferência
    • conciliar (Subcommand) — Registra o resultado da conferência de um anúncio
      • id (String, required) — ID do anúncio listado em incertos
      • resultado (String, required) — Confirme após verificar o canal
        • Mensagem encontrada (found)
        • Confirmado que não foi enviada (confirmed_absent)
      • mensagem (String, optional) — ID da mensagem encontrada, quando houver
    • bingo (Subcommand) — Agenda uma cartela comunitária de bingo
      • inicio (String, required) — Primeiro dia, AAAA-MM-DD (Recife)
      • fim (String, required) — Último dia, AAAA-MM-DD (Recife)
      • multiplas (Boolean, required) — Uma ação pode preencher várias casas?
    • conversa (Subcommand) — Inicia uma conversa sobre uma partida encerrada
      • dia (String, required) — Data da partida encerrada, AAAA-MM-DD
  • wordlist (SubcommandGroup) — Gerenciar a wordlist do Termo
    • review (Subcommand) — Revisa a próxima palavra pendente da wordlist.txt

/games

Section titled “/games”

Central de jogos do Marquinhos - 7 mini games disponíveis!

  • Discord permissions No explicit member permission flag.
  • Cooldown No Sapphire cooldown configured.
  • list (Subcommand) — Ver todos os jogos disponíveis
  • play (Subcommand) — Iniciar um jogo específico
    • game (String, required) — Escolha o jogo
      • 🎰 Caça-níqueis (slots)
      • 🃏 Blackjack (blackjack)
      • 🎲 Dados Mágicos (dice)
      • 🔫 Roleta Russa (roulette)
      • ⭕ Jogo da Velha (tic_tac_toe)
      • ✂️ Pedra, Papel, Tesoura (rock_paper_scissors)
      • 🏃 Labirinto (maze)
    • oponente (User, optional) — Marque um oponente para jogos multiplayer
  • stats (Subcommand) — Ver suas estatísticas de jogos
  • ranking (Subcommand) — Ver ranking dos melhores jogadores
