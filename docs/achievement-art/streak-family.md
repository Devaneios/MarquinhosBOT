# Winning streak flame family

Direction agreed with the user: red at the early tiers, then gold, then violet.
The user explicitly approved all five displayed badges together.

## Shared emblem

Use the flame silhouette proposed in `src/streak_3.txt`: one tall tongue,
smaller side tongues and a solid inner core. Keep its silhouette, size,
position and core layout identical across all five tiers. Leave a margin
around the emblem. No numbers or detached sparks.

## Planned progression

| Badge | Finish |
| --- | --- |
| `streak_3` | Simple red `F` flame with a solid gold `Y` core. |
| `streak_7` | Same red flame and core, with restrained coral `E` highlights. |
| `streak_14` | Polished red, coral highlights, sparse deep-red `M` shading and cream `H` light inside the same core. |
| `streak_30` | Gold `Y` flame, cream `H` core and upper-left highlights, restrained brown `S` shading. |
| `streak_100` | Violet `P` flame, light-violet `V` core and highlights, restrained deep-violet `D` shading. |

Keep small shapes solid and shading subordinate to the silhouette. Check
each candidate at native 16×16 against the first tier. The renderer's border
geometry stays fixed. All four rarity colors remain exclusive to the border.

At the user's request, the complete family was previewed together at native
16×16 before approval. The user approved `streak_3`, `streak_7`, `streak_14`,
`streak_30` and `streak_100` as displayed. All five entries are `approved`
in [`review-status.json`](../../apps/activity/achievement-art/review-status.json). Any future blueprint change requires renewed approval.
